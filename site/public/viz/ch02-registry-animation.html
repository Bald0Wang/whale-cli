# 工具注册表
_TOOLS: dict = {}
@tool(
    name="read_file",
    description="读取文件",
    parameters={...}
)
def read_file(path: str) -> str:
    return Path(path).read_text()
_TOOLS 注册表状态
"read_file"
schema: { name, description, parameters }
fn: read_file
Key insight: 加工具只需要写函数 + 加 @tool 装饰器。_TOOLS 字典自动更新，主循环一行不用改。
