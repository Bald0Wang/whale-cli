tools.py源代码
# 工具注册表
_TOOLS: dict = {}
@tool(name="read_file",
      description="读取文本文件",
      parameters={...})
def read_file(path: str) -> str:
    return Path(path).read_text()

"read_file"
schema → { name, description, parameters }
fn → read_file
关键变化 新增工具时，Schema 和执行函数从同一处注册；主循环只读取 _TOOLS，不需要跟着工具数量反复修改。
